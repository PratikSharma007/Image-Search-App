# 🔍 Image Search App

A responsive Image Search App built using **HTML, CSS, and JavaScript**, powered by the Unsplash API.

Search for images using keywords and dynamically display results without refreshing the page.

## 🚀 Features

- Search images using keywords
- Fetch images dynamically using the Unsplash API
- Display search results using DOM manipulation
- Load more images using the Show More button
- Loading indicator while fetching images
- Basic API error handling
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Unsplash API

## ⚙️ How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/PratikSharma007/Image-Search-App.git
   ```

2. Open the project folder in VS Code.

3. Add your own Unsplash API access key in the JavaScript file.

4. Open `index.html` using Live Server.

## 🔑 API Used

This project uses the [Unsplash API](https://unsplash.com/developers) to fetch images.

You need your own Unsplash API access key to run the application.
